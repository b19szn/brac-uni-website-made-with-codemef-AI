# BRAC University Website

A modern, responsive, and accessible website for BRAC University built with vanilla HTML, CSS, and JavaScript. Features a premium dark theme with glassmorphism effects, smooth animations, and comprehensive academic program information.

## 🚀 Features

- **Modern Design System** - Dark premium theme with calibrated color tokens, glassmorphism, and consistent spacing
- **Responsive Layout** - Mobile-first approach, works beautifully on all device sizes
- **Interactive Components**:
  - Mobile-friendly navigation with hamburger menu
  - Tabbed program explorer for 6 academic schools
  - Animated statistics counters
  - Scroll-triggered reveal animations
  - Parallax hero background effects
  - Form validation with loading states
- **Accessibility First** - Semantic HTML, ARIA labels, keyboard navigation, focus management, reduced motion support
- **Performance Optimized** - No build step, no dependencies, minimal CSS/JS, hardware-accelerated animations
- **Real Content** - Authentic BRAC University information including all 6 schools, programs, admissions process, scholarships, and campus details

## 🛠 Tech Stack

- **HTML5** - Semantic, accessible markup
- **CSS3** - Custom properties (design tokens), CSS Grid/Flexbox, modern selectors, animations
- **Vanilla JavaScript (ES6+)** - Modular, event-driven architecture with IntersectionObserver API
- **Google Fonts** - Inter & Plus Jakarta Sans for typography
- **Inline SVG** - Scalable icons, no external icon library needed
